# 分级词汇与短语库（A1-B2）

## A1 基础词汇

### 日常问候
- Hello / Hi / Good morning / Good afternoon / Good evening
- How are you? / I'm fine, thank you. / Nice to meet you.
- Goodbye / See you later / Good night

### 数字与时间
- One to ten, twenty, thirty, hundred
- What time is it? / It's three o'clock. / half past / a quarter to
- Today / tomorrow / yesterday / now / later

### 颜色与描述
- Red / blue / green / yellow / black / white
- Big / small / hot / cold / good / bad / happy / sad

### 家庭成员
- Father / mother / brother / sister / son / daughter
- My family has four people.

### 食物饮料
- Rice / bread / milk / water / tea / coffee / juice
- I would like a cup of coffee, please.

### 基础动词
- Be / have / go / come / eat / drink / see / like / want
- I like apples. / I want some water.

## A2 基础词汇

### 出行交通
- Bus / train / taxi / car / subway / walk / ride
- How can I get to the station? / Turn left / Turn right / Go straight

### 购物场景
- How much is it? / It's ten yuan. / Too expensive / Cheap / Discount
- Size / color / try on / pay by card

### 日常活动
- Get up / go to work / have breakfast / watch TV / go to bed
- I usually get up at seven.

### 描述表达
- Beautiful / interesting / delicious / convenient / crowded
- It's a beautiful place. / This food is delicious.

### 常用短语
- At the moment / right now / every day / last week / next month
- A lot of / a little / a few / some / any

## B1 中级词汇

### 工作学习
- Experience / responsibility / colleague / deadline / meeting
- I have five years of experience in marketing.

### 观点表达
- In my opinion / I think / I believe / From my perspective
- It depends / I agree / I disagree / That's a good point

### 情感态度
- Excited / nervous / worried / proud / disappointed / grateful
- I'm really excited about the trip.

### 连接表达
- However / therefore / besides / in addition / as a result
- I was tired; however, I finished the report.

### 旅行词汇
- Reservation / luggage / departure / arrival / sightseeing
- I'd like to make a reservation for two nights.

## B2 高级词汇

### 论述表达
- Furthermore / moreover / nevertheless / consequently
- It is widely believed that... / There is no doubt that...

### 抽象概念
- Innovation / sustainability / globalization / efficiency
- The company focuses on innovation and customer service.

### 复杂情感
- Overwhelmed / skeptical / optimistic / pessimistic / indifferent
- I'm skeptical about whether AI will replace all jobs.

### 学术表达
- According to / in terms of / with regard to / on the contrary
- In terms of efficiency, remote work has clear advantages.

## 场景常用短语

### 餐厅点餐
- Could I have the menu, please? / I'd like to order...
- What do you recommend? / The bill, please. / Can I pay by card?

### 旅行问路
- Excuse me, how do I get to...? / Is it far from here?
- How long does it take? / Could you show me on the map?

### 酒店入住
- I have a reservation. / I'd like to check in.
- What time is check-out? / Could I get a wake-up call?

### 购物
- I'm just looking, thanks. / Do you have this in a larger size?
- Could I try it on? / I'd like to return this.

### 面试
- Let me introduce myself. / My strengths include...
- Why do you want this job? / What are your career goals?

## 表达升级建议

- I want → I'd like / I would like（更礼貌）
- Good → Great / Wonderful / Fantastic（更生动）
- Very good → Excellent / Outstanding（更高级）
- I think → In my opinion / I believe（更正式）
- Many → A lot of → A great number of（逐步升级）
