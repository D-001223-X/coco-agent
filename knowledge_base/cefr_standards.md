# CEFR 能力等级标准

## CEFR 等级总览

CEFR（Common European Framework of Reference for Languages，欧洲语言共同参考框架）将语言能力划分为 A1、A2、B1、B2、C1、C2 六个等级。可可语伴当前覆盖 A1-B2 四个等级。

| 等级 | 中文名称 | 核心能力描述 |
| :--- | :--- | :--- |
| A1 | 入门级 | 能理解和使用非常基础的短语和表达 |
| A2 | 基础级 | 能理解最直接相关领域的句子和表达 |
| B1 | 进阶级 | 能理解工作、学习、休闲等熟悉领域的标准输入 |
| B2 | 中高级 | 能理解具体和抽象主题的复杂文本 |

## CEFR 等级映射规则

可可语伴的水平测评总分为 46 分（听力 20 + 口语 15 + 阅读 11），映射规则如下：

| 总分区间 | CEFR 等级 |
| :--- | :--- |
| 0-19 分 | A1（入门级）|
| 20-29 分 | A2（基础级）|
| 30-39 分 | B1（进阶级）|
| 40-46 分 | B2（中高级）|

## A1 入门级能力标准

### 听说能力
- 能理解和使用非常基础的日常问候语和礼貌用语
- 能听懂慢速、清晰的简单对话（自我介绍、数字、日期、颜色、家庭成员）
- 能进行简单的自我介绍（姓名、年龄、国籍）

### 读写能力
- 能识别和书写基础高频词汇（约 500-800 词）
- 能阅读和理解非常简短的句子和公告

### 语法范围
- 一般现在时（be 动词、have）
- 基础疑问句（what、where、who、how much）
- 简单祈使句

## A2 基础级能力标准

### 听说能力
- 能理解与日常生活直接相关的句子（购物、出行、点餐）
- 能在简单场景中交换信息（问路、订餐、预约）
- 能用简单句式描述家人、朋友、日常活动

### 读写能力
- 词汇量约 800-1500 词
- 能阅读简短通知、简单邮件、菜单

### 语法范围
- 一般现在时、现在进行时、一般过去时
- can/could 情态动词
- 比较级与最高级

## B1 进阶级能力标准

### 听说能力
- 能理解工作、学习、休闲等熟悉话题的标准对话
- 能就熟悉话题表达个人观点并给出简单理由
- 能应对旅行中大部分场景

### 读写能力
- 词汇量约 1500-2500 词
- 能阅读简单文章、邮件、报告

### 语法范围
- 现在完成时、过去进行时
- 条件句（if 引导的第一、第二条件句）
- 被动语态
- 定语从句、宾语从句

## B2 中高级能力标准

### 听说能力
- 能理解具体和抽象主题的复杂文本，包括专业领域讨论
- 能与母语者流畅自然交流，无明显障碍
- 能清晰详细地阐述复杂观点

### 读写能力
- 词汇量约 2500-4000 词
- 能阅读专业文章、新闻报道

### 语法范围
- 虚拟语气
- 第三条件句
- 复杂复合句（多从句嵌套）
- 倒装句、强调句

## 难度适配规则

| 维度 | A1/A2 用户 | B1/B2 用户 |
| :--- | :--- | :--- |
| 词汇 | 基础高频词汇 | 中级词汇和短语 |
| 句式 | 简单句，1-2 个分句 | 复合句，3-4 个分句 |
| 语速 | 慢速，适当重复 | 正常语速，自然节奏 |
| 纠错频率 | 高，鼓励为主 | 适度，重点纠高频错误 |
